# 0.6 Nouvelle note dans la version SPA

L'utilisateur écrit une note dans le formulaire de `/exampleapp/spa` et clique sur **Save**.
Le formulaire n'ayant pas d'attribut `action`, c'est le gestionnaire `form.onsubmit` enregistré
par `window.onload` dans `spa.js` qui prend le relais.

```mermaid
sequenceDiagram
    participant browser as Navigateur
    participant server as Serveur (Express)

    Note over browser: L'utilisateur saisit le texte puis clique sur "Save"<br/>Déclenchement de l'événement submit

    browser->>browser: form.onsubmit s'exécute : e.preventDefault()<br/>→ la soumission classique est annulée, aucune navigation

    browser->>browser: note = { content: e.target.elements[0].value, date: new Date() }

    browser->>browser: notes.push(note) — mise à jour locale en mémoire

    browser->>browser: e.target.elements[0].value = "" — le champ de saisie est vidé

    browser->>browser: redrawNotes() réécrit le <ul> via le DOM<br/>→ l'utilisateur voit sa note immédiatement

    browser->>browser: sendToServer(note) :<br/>xhttpForPost.open('POST', '/exampleapp/new_note_spa', true)<br/>setRequestHeader('Content-Type', 'application/json')<br/>send(JSON.stringify(note))

    browser->>server: POST /exampleapp/new_note_spa<br/>Content-Type: application/json<br/>corps : { "content": "...", "date": "2026-09-30T21:29:43.000Z" }
    activate server
    Note right of server: Le serveur ne peut lire le corps que grâce<br/>à l'en-tête Content-Type (Express + body-parser json)
    server-->>browser: 201 Created + la note créée en JSON
    deactivate server

    Note right of browser: Le gestionnaire attend status == 201<br/>puis console.log(this.responseText)<br/>— c'est le seul cas où le serveur renvoie la note créée

    Note right of browser: Aucune redirection, aucun rechargement :<br/>la page n'est pas rechargée, le DOM reste intact
```

**Total : 1 seule requête HTTP.** C'est toute la différence avec l'exercice 0.4 :

| | Application traditionnelle (0.4) | Application monopage (0.6) |
| --- | --- | --- |
| Requêtes | 5 | 1 |
| Envoi des données | soumission de formulaire, `application/x-www-form-urlencoded` | JavaScript, `application/json` |
| Réponse du serveur | `302 Found` + redirection | `201 Created`, pas de redirection |
| Rendu de la nouvelle note | après rechargement complet de la page | immédiatement, avant la confirmation du serveur |

La note apparaît à l'écran **avant** d'être confirmée par le serveur : c'est le comportement
d'une application monopage.
